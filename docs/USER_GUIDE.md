# PhotoMind AI — 用户指南

## 一、安装与启动

### 便携运行（开发构建）

直接运行 `src/PhotoMind.App/bin/Debug/net8.0-windows/PhotoMind.App.exe`（需 .NET 8 桌面运行时；若用本地 SDK 运行需设 `DOTNET_ROOT` 指向 SDK 目录）。

### 正式安装（发布版）

1. 先按 `scripts/publish.ps1` 生成自包含 Release 发布产物。
2. 运行 `scripts/install.ps1`：复制到 `%LOCALAPPDATA%\Programs\PhotoMind AI` 并创建「开始菜单」快捷方式。
3. 卸载：运行 `scripts/uninstall.ps1`。卸载**不会自动删除**用户数据（数据库/配置/缓存），只有输入 `YES` 才删除，且**永远不动原始照片**。

## 二、界面总览

左侧导航 8 页：

1. **首页** — 概览入口。
2. **图片扫描** — 选择文件夹（可多选/选磁盘），递归扫描照片，生成缩略图并保存记录。
3. **AI 智能分类** — 选择分类模式，启动 DeepSeek 视觉识别。
4. **分类审核** — 筛选/批量修改/确认分类结果。
5. **照片整理** — 按分类把照片复制/移动到目标目录（默认复制）。
6. **分类管理** — 增删改分类体系。
7. **历史任务** — 查看扫描/分类/整理任务、重复图片、API 用量。
8. **设置** — API Key 管理、AI 配置、隐私开关。

## 三、首次使用（三步）

1. **扫描**：进入「图片扫描」，点「选择文件夹」选照片目录，点「开始扫描」。
2. **配 Key**：进入「设置」，粘贴 DeepSeek API Key，点「保存」，再点「测试连接」验证。
3. **分类**：进入「AI 智能分类」，选模式（默认 AI 自动），点「开始分类」。

## 四、三种分类模式

- **AI 自动**：AI 自由分类，新分类自动创建并标记待审核。
- **用户自定义（Fixed）**：AI 只能选已有分类，否则标为"未分类/待审核"。
- **混合（Hybrid）**：优先匹配已有分类，可建议新分类。

## 五、照片整理（安全说明）

1. 选目标目录（如 `E:\PhotoMind_Output`）→ 点「预览」看整理计划（含冲突/空间）。
2. 选操作类型：**仅建目录 / 复制（默认）/ 移动**。
3. 勾选确认后点「开始整理」。
4. **移动**需要二次确认；跨盘移动先复制校验再删源，失败不删源。
5. 同名冲突自动改名 `photo_1.jpg`，绝不覆盖。
6. 可用「撤销」恢复（复制删副本、移动按日志移回，同名不覆盖）。

## 六、隐私与安全

- **默认不上传任何图片**，只有主动启动 AI 分类才发送缩小的预览图。
- 扫描/分类**只读原图**，绝不改/移/改名/删。
- AI 只给建议，所有文件操作由 C# 执行并经用户确认。
- API Key 用 Windows DPAPI 加密存储，不写日志/git/配置。
- 删除应用记录**不动原图**。

## 七、常见问题

- **测试连接失败**：确认网络可访问 `https://api.deepseek.com`，Key 未过期、余额充足。
- **提示"余额不足"**：DeepSeek 控制台充值后再试。
- **分类失败但扫描正常**：检查设置页 `允许 AI 上传` 是否打开、Key 是否有效。
- **整理时空间不足**：预览阶段会检查磁盘空间，清理后重试。
- **原图会变吗**：不会。扫描/分类全程只读，整理默认复制；移动操作前会二次确认。
